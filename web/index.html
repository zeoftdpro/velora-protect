Velora Protect · sécurité des sites et applications

Votre site est-il vraiment protégé ?

Glissez le dossier de votre projet ou saisissez l'adresse de votre site : Velora repère les failles, le code malveillant, les secrets oubliés et les mauvaises configurations, puis vous donne la configuration à copier pour corriger.

  • Score de sécurité /100
  • Indice de confiance /100 : à quel point vous pouvez vous fier au score
  • Code malveillant : portes dérobées, webshells, mineurs, scripts piégés

Le code malveillant

Portes dérobées et webshells PHP, code décodé puis exécuté, mineurs de cryptomonnaie, vol de cookies, iframes invisibles, redirections cachées d'un site piraté, scripts d'installation npm/Python piégés, fichiers PHP cachés dans un dossier d'images.

La confiance

Chaque analyse a un indice de confiance /100 : langages couverts par des règles, dépendances vérifiées avec leur version exacte, fichiers réellement lus. Vous savez ce que le score vaut, et pourquoi.

Le code

XSS, injections SQL et de commande, inclusion de fichiers, SSRF, cookies, CSRF, clés API et mots de passe laissés dans le code, dépendances vulnérables (base OSV.dev). React, Vue, PHP, WordPress, Python, HTML/CSS, C/C++, Java, .NET, Go…

Les applications

Connexion sans limite de tentatives, mots de passe mal hachés. Mobile : Android, iOS, Flutter, React Native (app débogable, trafic en clair, certificats non vérifiés, jetons stockés sans chiffrement).

Le site en ligne

HTTPS et certificat, protocoles obsolètes, en-têtes de sécurité, cookies, CORS, source maps et clés dans les scripts publiés, et sur preuve de propriété : fichiers sensibles accessibles (.env, .git, sauvegardes).

Confidentialité

Le code est analysé dans votre navigateur et n'est jamais envoyé. Seuls les noms et versions des dépendances sont envoyés à OSV.dev (désactivable). Aucun cookie, aucun traceur.

Analyse automatique par heuristiques : chaque constat est à vérifier, et un bon score ne garantit pas l'absence de faille. Pour une application sensible, rien ne remplace un audit humain.
